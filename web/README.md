## 一、AI 对话功能

  通过 `!ai <内容>` 命令与 DeepSeek Chat 对话，AI 能识别播放指令并自动控制机器人。

  ### 配置

  在网页设置 → AI 设置中填入 DeepSeek API Key 即可启用。

  ### 命令

  - `!ai <问题>` — 向 AI 提问，AI 可以自动执行播放命令

  ### 注意事项

  - 需要 DeepSeek API Key（从 platform.deepseek.com 获取）
  - AI 回答会被截断到 200 字以内

 ## 二、加入欢迎功能

  用户进入机器人所在频道时自动发送频道欢迎，进入服务器默认频道时发送全局服务器欢迎。可在网页设置中独立开关。

  ### 配置方法

  在网页设置 → 机器人 Profile → 加入欢迎，开启后机器人会在用户加入频道时发送欢迎消息。

  ### 注意事项

  - 切换频道后 3 秒内不发欢迎
  - 支持频道欢迎和服务器欢迎两种类型
